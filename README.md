AttendEase 📚

AttendEase is a student-friendly attendance management web app designed to make attendance calculations simple and stress-free.

Students can calculate their current attendance, find out how many classes they can miss, plan attendance for upcoming classes, and track attendance subject-wise.

🌐 Live Demo

AttendEase: https://anishtha62-glitch.github.io/AttendEase/

✨ Features

- 📊 Calculate current attendance percentage
- 🎯 Set your required attendance percentage
- ⚠️ Check whether your attendance is above or below the target
- 📚 Find how many classes you can miss while maintaining the required attendance
- 📅 Plan attendance for upcoming classes
- 📖 Track attendance subject-wise
- 📱 Responsive design for mobile and desktop
- 🎨 Modern glassmorphism-style user interface

🚀 How to Run Locally

1. Clone the repository:

git clone https://github.com/anishtha62-glitch/AttendEase.git

2. Open the project folder.

3. Open "index.html" in your browser.

No additional installation is required.

🎯 Purpose

AttendEase was created to help students easily understand and manage their attendance without manually performing calculations every time.
